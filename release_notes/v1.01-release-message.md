# v1.01 — Title-page author block: project email + website

A **metadata-only point release** that brings the title-page
contact info into alignment with the project domain
`geometryinducedphysics.org`.

**No scientific content changes.**  No audit-table updates; no new
sections, figures, or experiments.  Body of the paper, audit
table, and all sections from §1 onward are byte-for-byte
unchanged from v1.0.

The `v1.01` numbering (rather than `v1.1`) signals the patch-scale
of the change.

This is **Paper~II of the A=1 Discrete Causal Lattice series**.

## What changed

*Author block (project-domain migration):*

- Email is now `jack@geometryinducedphysics.org` (replaces
  personal gmail).
- New `Web:` line in author block linking to
  <https://geometryinducedphysics.org/>.

*Title-page metadata:*

- Footnote: `Version 1.0` -> `Version 1.01`; DOI reference
  updated to the v1.01 deposit.
- Inline *Data availability* block: tag reference `v1.0` -> `v1.01`;
  DOI updated to the v1.01 deposit (consistent with the title-page
  footnote).

## Why v1.01

The project email and domain (`geometryinducedphysics.org`) were
established between Paper~II's v1.0 deposit (2026-05-16) and this
release.  Bringing Paper~II's PDF into alignment with the
project-domain contact info keeps the series consistent with
Paper~I's parallel v1.01 release
([10.5281/zenodo.20291342](https://doi.org/10.5281/zenodo.20291342)).

The v1.0 Zenodo record's metadata (author email field) was updated
separately via the Zenodo UI; v1.01 aligns the published PDF with
that metadata update.
