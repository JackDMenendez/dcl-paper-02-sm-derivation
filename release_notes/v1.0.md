## Why v1.0

v1.0 is the first canonical, citable release of Paper II.  It closes
all five phases of `notes/work_plan.md` and settles the central
conjecture (Eq.~(137) of Paper I) to a precise structural
characterisation.  The conjecture's "either derivation or
obstruction" terminal states (as written in v0.1-DRAFT) have been
replaced by a sharper third outcome: **containment $\supseteq$ holds,
equality $=$ does not, and the gap is exactly the SU(6)$\oplus$SU(6)$\oplus$U(1)
left-right symmetric structure of which the SM gauge group is the
factor-product projection.**  This is the headline result of the
release.

## Summary of changes since v0.1-DRAFT

### New experimental work (sympy verification)

All scripts new to v1.0; v0.1-DRAFT carried only the six scaffolding
scripts inherited from Paper I.

1. **`su3_branch_consistency.py`** (Phase 1 sub-task 0; PASS) --
   only Branch A SU(3) ($\mathbf{3} \oplus \mathbf{3}$) admits the
   existing bipartite tick rule as a global symmetry; Branch B
   ($\mathbf{3} \oplus \bar{\mathbf{3}}$, the QCD colour vs
   anti-colour identification) obstructs on the 5 real Gell-Mann
   generators.
2. **`chirality_parity_alignment.py`** (Phase 1 Route a; PART) --
   the unique linear bipartite parity is $P = \sigma_x \otimes I_2
   \otimes I_3$; it anticommutes with $\gamma_5$, swaps $L
   \leftrightarrow R$, and commutes with $SU(2)_W$ (vector-like, not
   chiral coupling).  Lattice's bipartite $\mathbb{Z}_2$ and SM
   chirality $\mathbb{Z}_2$ are orthogonal Bloch involutions on the
   chirality $\mathbb{C}^2$.
3. **`tick_rule_cp_modified.py`** (Phase 1.5 Route b; FAIL) --
   no antilinear modification of the natural form
   $T_\text{ext}^B = is\,I_{12} + c\,(\sigma_x \otimes I_2 \otimes C) \circ K$
   admits Branch B SU(3); the obstruction reduces to anticommutation
   $\{\lambda_a, C\} = 0$ for every Gell-Mann, which has no
   non-zero solution.  Representation-theoretic: $\mathbf{3}$ and
   $\bar{\mathbf{3}}$ are inequivalent SU(3) irreps.
4. **`su3_generation_from_colour_memory.py`** (Phase 2; PASS) --
   the natural "rotate-toward-$|j\rangle$" colour-memory tick rule
   ($X_1 = \lambda_1 + \lambda_4$) closes under Lie brackets to the
   full $\mathfrak{su}(3)$.  Discrete RGB $\mathbb{Z}_3$ recovered as
   the abelian-Cartan corner.
5. **`automorphism_centralizer_extended.py`** (Phase 3; PART) --
   the discrete-Hermitian centralizer of the bipartite tick rule on
   $\mathbb{C}^{12}$ is $\mathfrak{su}(6) \oplus \mathfrak{su}(6)
   \oplus \mathfrak{u}(1)$ (dim 71), with the SM gauge subalgebra
   (dim 12) as the factor-product subalgebra and 59 coset
   generators ($(\mathbf{8}, \mathbf{3})$ leptoquark-flavoured +
   chirality-shadow SM).
6. **`aut_centralizer_extras_commutators.py`** (Phase 3 extension)
   -- bracket structure: 0/708 brackets $[E, T]$ land in SM
   (extras is SM-invariant module); 226/1711 brackets $[E_i, E_j]$
   land in SM (extras is not a Lie ideal).  The 71-dim algebra has
   the standard subalgebra-with-complement structure of a simple
   semisimple Lie algebra: SM is a non-normal subalgebra, extras
   is its complement, the structure is the algebraic shape of a
   broken-symmetry pattern $SU(6) \times SU(6) \times U(1) \to $
   SM.
7. **`induced_gauge_action_nonabelian.py`** (Phase 4; PART) --
   non-abelian generalisation of Paper I's bipartite-plaquette
   Q-tensor (eigenvalues $\{4, 4, 16\}$).  Spectator-factor
   counting gives lattice-scale ratios $g_1^2 : g_2^2 : g_3^2 = 1 :
   4 : 6$, sharp prediction $g_3^2/g_2^2 = 3/2$ independent of the
   universal one-loop prefactor (still open).

## What is not in v1.0 (explicit follow-on scope)

- The explicit one-loop $-\mathrm{Tr}\,\ln D_\text{lat}[U]$
  calculation for the universal prefactor $c$ of the induced gauge
  action.  Paper I left this open; Paper II inherits the open
  item.  A future paper would close it and convert the framework's
  ratio prediction $g_3^2/g_2^2 = 3/2$ into an absolute prediction.
- Fixing the lattice scale $1/a$ from first principles.  Without
  it, the framework's UV-scale ratios cannot be RG-evolved to
  $M_Z$ for direct comparison with measured couplings.
- The decoherence calculation sketched in
  `notes/extras_as_a1_accounting.md`.  The script
  `decoherence_as_projection.py` is named in the note but not
  written; converting the structural hypothesis into a quantitative
  prediction is left for follow-on work.
- The symmetry-breaking mechanism that takes the framework's 71-dim
  centralizer to the SM's effective 12-dim gauge sector.  Whether
  this is Higgs-analogous, decoherence-driven via the algebraic
  projection of `extras_as_a1_accounting.md`, or geometric in some
  other sense is the natural next paper in the series.
- Cross-paper bibliography expansion.  `paper-bib/references.bib`
  remains the empty seed at v1.0; the paper cites Paper I (via DOI
  in the title-page `\thanks{}` block and the introduction's
  Programme paragraph) and standard reference works informally in
  the prose.  A bibliography pass is appropriate for a v1.1
  maintenance release.

## Reproducibility

A fresh clone of the v1.0 tag reproduces every PASS / PART / FAIL
row in `paper/sections/audit_table.tex` from a Python venv with
`sympy`.  Setup:

```sh
git clone https://github.com/JackDMenendez/dcl-paper-02-sm-derivation
cd dcl-paper-02-sm-derivation
git checkout v1.0
python -m venv .venv-ucrt64
source .venv-ucrt64/bin/activate   # or .venv-ucrt64/Scripts/activate on Windows
pip install -r virtual-env-requirements.txt
```

Each script runs in seconds to a few minutes on a consumer-grade
laptop:

```sh
python -m src.utilities.automorphism_discrete
python -m src.utilities.automorphism_rgb_su3
python -m src.utilities.automorphism_direct_product
python -m src.utilities.automorphism_direct_product_extended
python -m src.utilities.tick_rule_extended_consistency
python -m src.utilities.tick_rule_gauge_invariance
python -m src.utilities.su3_branch_consistency
python -m src.utilities.chirality_parity_alignment
python -m src.utilities.tick_rule_cp_modified
python -m src.utilities.su3_generation_from_colour_memory
python -m src.utilities.automorphism_centralizer_extended
python -m src.utilities.aut_centralizer_extras_commutators
python -m src.utilities.induced_gauge_action_nonabelian
```

The most expensive script is `aut_centralizer_extras_commutators.py`
(several minutes for the $[E_i, E_j]$ closure check on a 71-dim
centralizer basis); all others complete in seconds.

Building the paper PDF:

```sh
make paper       # produces build/Paper.pdf via pdflatex
```

(GNU Make >= 4.3 required; the chocolatey/MSYS2 builds work.)
