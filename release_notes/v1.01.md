# v1.01 Release Notes

**Released:** 2026-05-19
**Prior version:** v1.0 (released 2026-05-16)
**Tag:** v1.01
**DOI:** [10.5281/zenodo.20292158](https://doi.org/10.5281/zenodo.20292158)
**Prior-version DOI:** [10.5281/zenodo.20240736](https://doi.org/10.5281/zenodo.20240736)
  (Paper II v1.0)

## Why v1.01

v1.01 is a **metadata-only point release** that brings the
title-page author block into alignment with the project domain
`geometryinducedphysics.org`:

- Author email: `jack@geometryinducedphysics.org` (replaces personal
  gmail).
- New `Web:` line in the author block linking to
  <https://geometryinducedphysics.org/>.
- Title-page footnote `Version 1.0` -> `Version 1.01`; DOI
  reference updated to the v1.01 deposit.
- Inline *Data availability* block: tag reference `v1.0` -> `v1.01`;
  DOI reference updated to the v1.01 deposit (consistent with the
  title-page footnote).

No scientific content changes; no audit-table changes; no changes
to experiments, scripts, notes, or bibliography.  The `v1.01`
numbering (rather than `v1.1`) signals the patch-scale of the
change: the body of the paper, the audit table, and all sections
from §1 onward are byte-for-byte unchanged from v1.0.

## Why this is worth its own release

The project email and domain (`geometryinducedphysics.org`) were
established between Paper II's v1.0 deposit (2026-05-16) and this
v1.01 release.  Bringing Paper II's PDF and CITATION metadata into
alignment with the project-domain contact info keeps the series
consistent with Paper I's parallel v1.01 release
([10.5281/zenodo.20291342](https://doi.org/10.5281/zenodo.20291342)).

The v1.0 Zenodo record's metadata (author email field) was updated
separately via the Zenodo UI to use the project email; v1.01
aligns the published PDF with that metadata update.

## Summary of changes since v1.0

- Title-page author block: project email + website
  (`paper/main.tex`).
- Title-page footnote: version `1.0` -> `1.01`; DOI reference
  updated to `10.5281/zenodo.20292158`.
- Inline *Data availability* block: tag `v1.0` -> `v1.01`; DOI
  updated to the v1.01 deposit.
- `CITATION.cff`: version `v1.0` -> `v1.01`; date-released
  `2026-05-16` -> `2026-05-19`; DOI updated to the v1.01 deposit.

### Not changed

- Paper body, sections, appendices, figures, audit table.
- Experiments, scripts, notes, bibliography.
- Front-matter layout (Paper II already had the conventional
  Abstract -> Keywords -> License -> Data availability order; the
  layout reorder applied to Paper I's parallel v1.01 release does
  not apply here).

## Build

Build from a recent TeX Live distribution + GNU Make >= 4.3.

*Build note (TeX Live 2026):* the default `openout_any=p` security
setting blocks bibtex's parent-directory output paths.  Set
`openout_any=r` in the environment if the build hits an
"openout_any = p; no extended check" error from bibtex.
