Paper II of the A=1 Discrete Causal Lattice series.  v1.0 closes
the central conjecture of Paper I (Eq.~137 of *Geometry First*,
[DOI: 10.5281/zenodo.20078529](https://doi.org/10.5281/zenodo.20078529))
to a precise structural **characterisation**: the Lie-algebra
$\mathfrak{so}(3,1) \oplus \mathfrak{su}(3) \oplus \mathfrak{su}(2)
\oplus \mathfrak{u}(1)$ of the Standard Model gauge group plus
Lorentz is contained in the lattice's automorphism algebra, but
**equality does not hold** -- the discrete-Hermitian centralizer of
the bipartite tick rule on $\mathbb{C}^{12}$ is the left-right
symmetric algebra $\mathfrak{su}(6) \oplus \mathfrak{su}(6) \oplus
\mathfrak{u}(1)$ of dim 71, with the SM gauge group recovered as its
factor-product subalgebra.  The 59 coset generators transform as
$(\mathbf{8}, \mathbf{3})$ leptoquark-flavoured plus chirality-shadow
SM under the SM adjoint action -- a GUT-style broken-symmetry shape
derived from $\mathcal{A}=1$ on the bipartite octahedral lattice,
not postulated.

## Why this is v1.0 and not v1.0-RC

All four phases of `notes/work_plan.md` are closed.  Phase 1
(chirality alignment, PART) found bipartite parity is spatial
parity, not chirality projection; Phase 1.5 (modified tick rule
for SM-CP, FAIL) ruled out any natural antilinear modification
admitting Branch B SU(3); Phase 2 (PASS) generated the full
$\mathfrak{su}(3)$ from the colour memory; Phase 3 (PART)
identified the centralizer as $\mathfrak{su}(6) \oplus
\mathfrak{su}(6) \oplus \mathfrak{u}(1)$; Phase 4 (PART) derived
the sharp ratio prediction $g_3^2/g_2^2 = 3/2$ at the lattice
scale.  The audit table is v1.0-frozen.  All claims are
symbolically verified by `sympy` scripts under `src/utilities/`.

  Sharp prediction $g_3^2 / g_2^2 = 3/2$ at the lattice scale,
  derived from spectator-factor counting on the per-site

  No antilinear $C$ anticommutes with every Gell-Mann; the lattice

## Reproducibility

A fresh clone of the v1.0 tag reproduces every audit-table row
from `sympy` alone, with no specialised lattice-gauge-theory
infrastructure required.  The most expensive script
(`aut_centralizer_extras_commutators.py`, 1711 brackets) completes
in a few minutes; all others run in seconds.

```sh
git clone https://github.com/JackDMenendez/dcl-paper-02-sm-derivation
cd dcl-paper-02-sm-derivation
git checkout v1.0
python -m venv .venv-ucrt64
source .venv-ucrt64/bin/activate
pip install -r virtual-env-requirements.txt
make paper                              # build the PDF
python -m src.utilities.automorphism_discrete  # ... and the 12 other scripts
```

See `release_notes/v1.0.md` for the full reproducibility instructions.
